How the scores work

FeasibilityDoes the plan follow every rule?

The share of tasks where the submitted plan passes all of the hidden checks, such as capacity, timing and demand rules.

DAQThe overall score

Each task is scored 0 if the plan breaks a rule. Otherwise its result is compared with the expert’s, where 1 means just as good. The overall score is the average over all 31 tasks.

DAQ = 1/N · Σi 1[feasiblei] · qi

qi compares the result on task i with the expert’s.

DAQαA stricter version

An average lets good tasks make up for bad ones. DAQα weighs low-scoring tasks more as α rises from 1 to 3. At α = 1 it equals DAQ; the experts stay at 1 throughout.

The coding tool matters too: in a separate run with Codex instead of Claude Code (paper, Appendix D.7), GPT-5.6 Sol scored 93.59% ± 7.31. Those runs are not part of this ranking.
