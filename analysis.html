Analysis

Beyond the score.

The leaderboard shows who comes out ahead. These charts help explain why: whether the ranking holds up, how agents dig into problems, when they ask the client, what goes wrong, and which methods they reach for. Each chart redraws a figure from the paper; open “View chart values” under it for the exact numbers.

01 · Stricter scoring

Does the ranking hold up under stricter scoring?

DAQ is an average, so strong results on some tasks can make up for failures on others. DAQα adds a setting, α: the higher it is, the harder low-scoring tasks pull the score down.

02 · Digging into problems

Do agents get to the bottom of problems?

When a run fails or a result looks wrong, a good analyst guesses the cause and explains it, runs a test, reads the result, and then changes the model. The paper’s experts traced how far agents got each time.

03 · Asking the client

When do agents ask the client?

Agents can ask ORSim, the simulated client, at any stage. In practice they ask most of their questions before they start writing solver code.

04 · Mistakes

What goes wrong?

Experts went through each agent’s work and sorted every mistake by where it started. For 9 of the 11 models, the most common mistakes are in how the problem was set up, not in the code.

05 · Methods

Which methods do agents use?

Experts labeled the methods behind each final solution and compared them with the experts’ own solutions. Agents lean more on simple rules and on listing out candidates; experts more often split the problem up and narrow the search.
